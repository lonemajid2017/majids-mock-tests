Is app mein 7 Automatic External File Slots pehle se lage hue hain. Kal ko aapko index.html ka code dubara delete ya edit nahi karna padega — bas GitHub mein Create new file karke niche diye gaye naam se file bana dena:

  • geography.js → Geography ke sets apne aap unlock ho jayenge.
  • civics.js → Civics / Indian Polity ke sets apne aap unlock ho jayenge.
  • jkgk.js → Jammu & Kashmir GK ke sets apne aap unlock ho jayenge.
  • reasoning.js → Reasoning & Mental Ability ke sets apne aap unlock ho jayenge.
  • fullmocks.js → Syllabus khatam hone par Full-Length Mock Tests apne aap unlock ho jayenge.
  • extra_questions.js → Kisi bhi purane topic (jaise Articles ya History) mein naye sets add karne ke liye.
  • patches.js → Agar future mein app ke kisi feature ya design mein koi bhi badlav/theek karna ho, toh bina index.html chhue sirf patches.js add karne se app update ho jayegi!
