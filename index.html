📘 GitHub Pages Setup & Future File Guide (For Majid)

✅ Abhi GitHub Par Kya Karna Hai (Sirf 1 File!):

Aapko bar-bar files edit ya delete karne ki bilkul zaroorat nahi hai. Is single index.html file ke andar hi poora English (9 Topics × 10 Sets = 4,500 Questions) aur Modern History (15 Sets × 50 Questions = 750 Questions) pehle se maujood hai!

  1. Apne GitHub repository mein jayein. Purani broken files hata dein.
  2. Add file → Upload files (ya Create new file) par click karein.
  3. File ka naam bilkul small letters mein index.html rakhein aur yeh code save/commit kar dein.
  4. Settings → Pages mein jakar Branch main select karke Save karein. Aapki app hamesha ke liye bina kisi error ke chalegi!
🚀 Future Mein Geography Aur Civics Kaise Add Karein (Bina index.html Ko Chhue!):

Is index.html mein Auto-Loader laga hua hai jo har baar khulne par apne aap geography.js aur civics.js ko check karta hai:

  • Jab aapko Geography ke questions add karne honge, tab aap index.html ko हाथ bhi nahi lagayenge! Bas GitHub mein Create new file karke uska naam geography.js rakhenge aur code paste kar denge — Geography apne aap chalu ho jayega!
  • Jab aapko Civics ke questions add karne honge, tab bas GitHub mein civics.js naam ki nayi file banayenge — Civics apne aap chalu ho jayega!
